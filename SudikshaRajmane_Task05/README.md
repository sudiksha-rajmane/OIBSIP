# 📚 Digital Library Management System – Java

## 📌 Project Overview

The **Digital Library Management System** is a console-based Java application developed as part of my **Oasis Infobyte Java Development Internship – Task 5**.

The application provides a simple library management system with separate **Admin** and **User** functionalities. It allows the administrator to manage books, while users can view, issue, and return books.

The project is developed using **Core Java and Object-Oriented Programming concepts**.

---

## 🎯 Objective

The main objective of this project is to develop a simple digital library system that manages books and provides different functionalities for administrators and users through a menu-driven console interface.

---

## ✨ Features

### 👨‍💼 Admin Features

- 🔐 Admin Login
- ➕ Add New Book
- ✏️ Update Book Details
- 🗑️ Delete Book
- 🔍 View Specific Book
- 📚 View All Books
- 🚪 Admin Logout

### 👤 User Features

- 🔐 User Login
- 📚 View Available Books
- 🔍 Search/View Specific Book
- 📖 Issue Book
- ↩️ Return Book
- 🚪 User Logout
