# 🏦 ATM Interface – Java

## 📌 Project Overview

The **ATM Interface** is a console-based Java application developed as part of my **Oasis Infobyte Java Development Internship – Task 3**.

The project simulates basic ATM and banking operations such as user registration, login, cash withdrawal, deposit, fund transfer, balance checking, and transaction history.

The application is designed using **Core Java and Object-Oriented Programming (OOP) concepts**.

---

## 🎯 Objective

The main objective of this project is to develop a simple ATM system that allows users to securely log in and perform basic banking transactions through a menu-driven interface.

---

## ✨ Features

- 👤 User Registration
- 🔐 User Login Authentication
- 💰 Check Account Balance
- 💵 Withdraw Money
- 💳 Deposit Money
- 🔄 Transfer Money
- 📜 View Transaction History
- ✅ Input Validation
- ⚠️ Insufficient Balance Handling
- 🚪 Exit Option

---
